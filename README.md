# 招标文件快速解压工具

一个针对电子招投标平台导出容器格式的快速解压工具。全国各地的电子招投标交易平台以「XML 包装 Base64‑ZIP」的形式发布招标项目文件（如 `.zf`、`.cf`、`.xczf`、`.tlzf` 等），这些文件无法用普通解压软件打开——本工具将其解压为可直接使用的 PDF、造价清单和项目数据文件。

## 核心特性

- **广泛兼容**：凡以 `zf` / `cf` 结尾的扩展名一律接受（任意字母/数字前缀），内置常见格式 + 未知新格式自动学习记忆
- **格式学习**：成功解压未知格式后自动记录其 XML 内容标签（`xxFileContent` 泛化匹配），下次自动识别
- **双哈希校验**：解压全程累计 CRC‑32 并与容器内置记录比对，解密/解压产物损坏立即拦截（防止 AES 密钥/算法错误导致的错误文件混入）；解压后自动生成 `_SHA256SUMS.txt`（sha256sum 兼容格式）供人工核验
- **附件识别与跳转下载**：解析容器内元数据（如 `PBZB.xml`，含被排除写盘的内部文件）识别 `<ZBFileCAD><CADFile>` 风格的图纸/清单控制价等下载链接；解压完成后 GUI 自动弹出「可下载附件」面板（按分类列名、多选/全选），点击「浏览器下载」调用系统浏览器打开链接——附件多为招投标平台登录后下载（需会话/鉴权），浏览器直接打开最可靠
- **可取消**：GUI 解压中可随时取消；取消不计入失败
- **单条目容错**：ZIP 内部单个坏条目只跳过并告警，其余文件照常解压
- **后台线程**：解压不阻塞界面，日志/进度实时刷新
- **防炸弹**：解压总量上限（默认 2 GB，可用环境变量 `EXTRACT_MAX_SIZE` 覆盖）
- **可插拔 AES 解密钩子**：通过 `decrypt_config.json` 配置密钥解密加密容器（默认关闭，密钥为空）

## 使用方式

### GUI

直接运行，支持：

- 拖放文件/文件夹到窗口
- 「选择文件」「选择文件夹」批量添加
- 双击列表条目打开所在文件夹
- 「SHA‑256 校验清单」「覆盖已存在文件」「完成后打开输出目录」开关（自动记忆）

### 命令行

```
招标文件快速解压工具.exe --auto [--quiet] [--recursive] [--no-checksum] [--out DIR] <文件或文件夹>
```

| 参数 | 说明 |
|---|---|
| `--auto` | 自动解压模式：解压完成后自动退出 |
| `--quiet` | 静默：不弹结果框、不自动打开输出目录（适合脚本） |
| `--recursive` | 目录递归扫描子目录 |
| `--out DIR` | 指定输出根目录（默认输出到源文件所在目录） |
| `--no-checksum` | 关闭 SHA‑256 校验清单生成（默认开启） |
| （无 `--download`） | 自动模式仅识别并记录附件摘要；下载在 GUI 的「浏览器下载」完成 |

退出码：`0` 全部成功；`1` 有失败或取消；`2` 未收到有效输入。

## 格式原理

交易平台导出的招标文件一般是：

```
<?xml …?>
<Tag>
  <XXFileContent>
    <base64 编码的 ZIP/>
  </XXFileContent>
</Tag>
```

工具流程：定位 XML 内容标签 → 流式 Base64 解码 → 解压 ZIP（校验 CRC‑32）→ 按 SHA‑256 生成校验清单；排除官方工具不导出的内部控制文件（如 `PBZB.xml`）。
